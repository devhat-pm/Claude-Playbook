# By role

What to actually do on Monday, by job. Each guide has the same six parts: 5 quick wins, 3 deeper setups (a Project, a custom skill, a scheduled task or Chrome automation), field-tested prompts with the reasoning behind them, guardrails, suggested connectors and skills, and a copy-paste Project instruction block. Every workflow cites its source, and anything that couldn't be checked is marked "(unverified)".

Do the [shared setup](_shared-setup.md) once first: Projects, memory, writing styles, connectors, skills, scheduled tasks, Claude in Chrome and the data-and-privacy checklist. The role guides link to it instead of repeating it.

| Role | Best first workflow |
|---|---|
| [Doctors and clinicians](doctors-and-clinicians.md) | Patient handout at a set reading level, from your own source text. Claude is not a clinical decision tool. |
| [Developers](developers.md) | Onboard to an unfamiliar codebase in one session, then go to [advanced/](../advanced/README.md) |
| [Designers](designers.md) | Mock up a screen in Claude Design on your own design system |
| [Researchers and academics](researchers-and-academics.md) | Citation audit of a reference list: verify every reference before it goes out |
| [SEO and content](seo-and-content.md) | Cluster a keyword export (CSV) into topics |
| [HR and recruiters](hr-and-recruiters.md) | Structured interview kit with a scoring rubric |
| [Marketers](marketers.md) | Campaign brief from a messy kickoff |
| [Finance specialists](finance-specialists.md) | Variance analysis from an uploaded .xlsx, tied out to source |
